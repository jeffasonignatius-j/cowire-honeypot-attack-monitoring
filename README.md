# Cowrie Honeypot Deployment & Attack Monitoring

## Project Overview
This project focuses on deploying and monitoring a Cowrie SSH/Telnet honeypot to observe and analyze suspicious login attempts and attacker interactions in a controlled environment.

## Objectives
- Understand how SSH/Telnet honeypots work.
- Capture suspicious login attempts.
- Monitor attacker interactions.
- Analyze collected security logs.
- Understand common attack patterns.

## Tools & Technologies
- Cowrie Honeypot
- Linux / Ubuntu
- SSH and Telnet
- Network Security
- Log Analysis

## Project Workflow
1. Set up the Cowrie honeypot in a controlled lab environment.
2. Configure SSH/Telnet honeypot services.
3. Monitor incoming connection attempts.
4. Collect authentication and session logs.
5. Analyze attacker activity and observed patterns.

## Key Learning Outcomes
- Understanding honeypot deployment.
- SSH/Telnet attack monitoring.
- Security log investigation.
- Basic attacker behavior analysis.
